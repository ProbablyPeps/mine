# Medieval Roguelite Platformer

This is a lightweight roguelite platformer game written in Python using
[Pygame](https://www.pygame.org/). It features a simple medieval theme with
randomized item drops and three short levels.

## Features

- Side-scrolling jump-and-run gameplay inspired by classic platformers
  like Mario.
- Three levels with different layouts.
- Ten unique items that can randomly spawn each game.
- Basic rogue-lite mechanics: item placement changes on each run and
  you keep the items you collect until you die.

## Requirements

- Python 3.11+
- Pygame (`pip install pygame`)

## Running the Game

```bash
pip install pygame
python -m medieval_roguelite.game
```

Use the arrow keys to move and space to jump. Reach the right side of each
level to progress. Collect items to gain bonuses.
